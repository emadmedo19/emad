# بيتي بلس | Beity Plus

تطبيق عربي لإدارة العمارات السكنية، مبني باستخدام React وVite.

## المميزات الحالية
- لوحة تحكم تعرض عدد الشقق والمتأخرات والمصروفات وطلبات الصيانة.
- إدارة الشقق والسكان: إضافة وتعديل وحذف وبحث.
- سجل المصروفات: تسجيل وتعديل وحذف المصروفات.
- طلبات الصيانة: إنشاء الطلبات وتغيير حالتها.
- إعلانات العمارة: نشر الإعلانات وحذفها.
- واجهة عربية RTL متجاوبة مع الموبايل والكمبيوتر.
- حفظ البيانات محلياً في المتصفح باستخدام localStorage.

## التشغيل محلياً
```bash
npm install
npm run dev
```

## بناء نسخة النشر
```bash
npm run build
```
ملفات النشر النهائية ستكون داخل مجلد `dist`.

## النشر على Netlify
- اربط مستودع GitHub بحساب Netlify.
- Build command: `npm run build`
- Publish directory: `dist`

## ملاحظة مهمة
هذه نسخة MVP تجريبية ببيانات محفوظة محلياً على الجهاز والمتصفح. لا يوجد حالياً تسجيل دخول حقيقي أو قاعدة بيانات مشتركة أو مزامنة بين أجهزة السكان. يلزم ربط Supabase وإعداد صلاحيات المستخدمين قبل استخدامها لإدارة عمارة فعلية.
